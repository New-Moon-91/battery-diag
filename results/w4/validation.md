# w4 [4] — 실증 검증: 모형이 예측한 것이 실거래에 나타나는가

생성 2026-08-20. 재현: `python scripts/validate_w4.py --policy results/w4/W7.json`
수치 파일: `results/w4/validation_price.csv`

**원자료 부재 고지.** 재캘리브레이션의 근거가 된 `입찰_재사용__0819.xlsx` /
`입찰_재활용__0819.xlsx` 는 이 머신에 없다(→ `BLOCKED_w4.md`). 아래 "실측" 값은
TASK [2] 가 준 차종별 **실측 손익배수**에서 항등식으로 되풀었다.

    r = (E[재사용] − p_rc·kWh) / (C_p/q_P)  ⇒  E[재사용] = r·973,753 + 9,491·kWh

되풀기가 옳음을 검산했다 — 이 식과 **구** 파라미터로 코나(64kWh, SOH 0.87)의 모형
함의 배율을 내면 **8.144** 로, TASK [0] 이 적은 "8.14배"와 소수 둘째 자리까지 맞는다.
따라서 아래 4개 차종의 실측 중앙값은 반올림 오차(±4,869원 = ±0.005·973,753) 안에서
정확하다. 나머지 3개 차종(니로·봉고3·아이오닉)과 94건 전수·기간별 분해는 원자료가
붙어야 낼 수 있다.

---

## §1 가격 예측 검증 — 재사용 낙찰단가

정밀검사 손익분기 `C_p/q_P` = 500,000 / 0.51348 = **973,753원**.
예측은 각 차종의 **2024년 이후 실측 SOH 중앙값**에서 평가한 `Erev(s, cap)` 이다.

| 차종 | 용량 kWh | SOH중앙 | 실측 중앙 | 예측 (v5) | 편의 (v5) | 예측 (w4) | 편의 (w4) |
|---|---:|---:|---:|---:|---:|---:|---:|
| SM3 | 26.6 | 0.670 | 301,147 | 649,150 | **+115.6%** | 359,618 | **+19.4%** |
| 쏘울 | 30.0 | 0.892 | 917,669 | 1,440,221 | **+56.9%** | 785,311 | **−14.4%** |
| 볼트 | 60.0 | 0.969 | 2,507,227 | 5,075,659 | **+102.4%** | 3,657,431 | **+45.9%** |
| 코나 | 64.0 | 0.861 | 3,421,569 | 4,443,787 | **+29.9%** | 3,326,570 | **−2.8%** |
| **중앙** | | | | | **+79.7%** | | **+8.3%** |
| **중앙절대오차** | | | | | **79.7%** | | **16.9%** |

네 차종 모두에서 편의가 줄고, 부호가 한 방향(전부 과대)에서 양방향으로 흩어진다 —
체계적 편의가 잡히고 잔차만 남았다는 뜻이다. TASK [0] 이 94건 전수로 낸 값은
**중앙편의 +65.1% → +10.7%, 중앙절대오차 65.2% → 28.9%** 다. 중앙편의는 4종 표본
(+79.7% → +8.3%)과 거의 같은 자리에 떨어지고, 중앙절대오차는 4종 쪽이 낮다
(16.9% vs 28.9%) — 이 넷은 전수 94건 중 상대적으로 잘 맞는 차종들이라는 뜻이다.
따라서 아래 표를 전수 성능의 대표값으로 읽으면 안 된다.

남은 최대 편의는 **볼트 +45.9%** 다. 볼트는 SOH 중앙이 0.969 로 넷 중 가장 높은데
헤도닉의 `g_s = 1.8912` 가 그 고SOH 구간에서 실거래보다 가파르다. §3 의 유일한
서열 역전도 여기서 나온다.

> **논문 문장** — "재캘리브레이션 후 재사용 낙찰단가 예측의 중앙편의는 +65.1% 에서
> +10.7% 로, 중앙절대오차는 65.2% 에서 28.9% 로 줄었다. 차종별로도 편의의 부호가
> 한 방향에서 양방향으로 흩어져, 남은 것은 체계적 편의가 아니라 잔차다."

## §2 배율 검증 — 재사용 / 재활용

배율 = `Erev(s,cap) / (p_rc·kWh)`. 재활용가는 모형에서 **차종 무관 상수** `p_rc` 다.

| 차종 | 모형 (v5) | 모형 (w4) | 실측 (pooled p_rc) |
|---|---:|---:|---:|
| SM3 | 2.80 | 1.42 | 1.19 |
| 쏘울 | 5.51 | 2.76 | 3.22 |
| 볼트 | 9.71 | 6.42 | 4.40 |
| 코나 | 7.97 | 5.48 | 5.63 |

구 파라미터의 배율은 **네 차종 모두에서** 실측을 웃돌았다 — 실측 대비 1.42~2.35배다.
새 파라미터에서는 0.86~1.46배로 좁아지고, 쏘울·코나는 실측을 밑돌고 SM3·볼트는 웃돈다.
§1 과 같은 방식으로 편의의 부호가 흩어진다.

### 남는 불일치 — p_rc 가 차종 무관인 데서 온다

TASK [0] 은 코나의 실측 배율을 **3.20** 이라 적었다. 위 표의 5.63 과 맞지 않는다.
산술을 풀면 원인이 하나로 특정된다. 실측 재사용 중앙이 3,421,569원이므로
배율 3.20 이 성립하려면 **코나 자신의** 재활용 중앙단가가

    3,421,569 / 3.20 / 64 kWh = 16,707 원/kWh   (pooled p_rc 9,491 의 **1.76배**)

여야 한다. 즉 `p_rc` 를 전 차종 하나의 중앙값으로 두는 모형의 단순화가, 대용량
팩(코나·볼트)의 재활용 가치를 **과소평가**하고 있다. 그 결과 이들의 모형 손익배수
`(E − p_rc·kWh)/(C_p/q_P)` 는 위쪽으로 밀린다. `_calib` 자신이 "p_rc 는 차종 무관,
시점 의존" 이라 적어 둔 한계가 여기서 정량적으로 드러난다.

민감도: 코나의 `p_rc` 만 16,707원/kWh 로 바꾸면 코나의 손익배수는 2.89 → **2.42** 로
내려간다. 볼트가 같은 비율로 움직이지 않는 한 §3 의 역전은 이 보정으로 해소되지 않는다.

**단서**: 3.20 이 어느 창(2024년 이후 vs 전기간)의, 어느 분모(코나 자신 vs 전차종)의
값인지는 TASK 본문에 없다. 위 해석은 "2024년 이후·코나 자신" 을 가정한 것이다.
원자료가 붙으면 확정할 수 있다. 기간별 분해도 거래일자 열이 있어야 가능하다.

> **논문 문장** — "재활용 단가를 차종 무관 상수로 두는 단순화는 대용량 팩의 재활용
> 가치를 과소평가한다. 코나 기준 실측 배율 3.20 을 맞추려면 코나 고유 재활용단가가
> 전차종 중앙값의 1.76배여야 하며, 그만큼 모형의 손익배수는 위쪽으로 편향된다."

## §3 구조 검증 — 가장 강한 증거

모형은 가격 실측을 **보지 않고** 정책을 낸다. 그 정책이 매기는 검사 강도의 서열이,
독립적으로 계산한 실거래 손익배수의 서열과 같은가.

검사 강도 = 창고에 들어온 그 차종 1대당 비율. 분모는 `sell+fast+pu+hold` 로,
도착 즉시 강제매각된 대수는 정책이 만진 적이 없으므로 뺀다.

### (a) 이분 판정 — 검사하느냐 마느냐

정책은 정확해가 닿는 가장 큰 인스턴스 **W=7** (\|S\|=245,157, g\*=3,977,934) 의 것이다.

| 차종 | 실측 손익배수 | 실측 분류 | 모형 정밀검사율 | 모형 분류 | |
|---|---:|:--:|---:|:--:|:--:|
| SM3 | 0.05 | R1 | 0.0% | R1 | 일치 |
| 쏘울 | 0.65 | R1 | 0.0% | R1 | 일치 |
| 볼트 | 1.99 | R2 | 62.7% | R2 | 일치 |
| 코나 | 2.89 | R2 | 36.3% | R2 | 일치 |

W=4·5·6 에서도 같은 4/4 일치다 (정밀검사율은 W 에 따라 볼트 71.8→62.7%,
코나 50.5→36.3% 로 움직이지만 0 대 양수의 이분은 바뀌지 않는다).

**4/4 일치.** 손익분기 1.0 의 아래에 놓인 두 차종은 모형이 정밀검사를 한 번도
쓰지 않고 즉시 매각하며, 위에 놓인 두 차종에만 자원을 쓴다.

같은 판정을 모형 내부 기준(`max_b V^PS` vs `V^S`)으로 매긴 `Instance.REG` 와도
대조했다. 새 파라미터에서는 **넷 다 일치**한다(`REG_AGREE`). 구 파라미터에서는
SM3(R3 vs R1)·쏘울(R2 vs R1) 둘이 어긋났다 — 재캘리브레이션이 실제로 고친 것이 이것이다.

### (b) 서열 — 한 쌍이 역전한다

| 기준 | 오름차순 | 켄달 타우 | 완전일치 |
|---|---|---:|:--:|
| 실측 손익배수 | SM3 < 쏘울 < **볼트 < 코나** | **+0.600** | 아니오 |
| 모형 손익배수 | SM3 < 쏘울 < **코나 < 볼트** | +1.000 | 예 |
| 모형 정밀검사율 | SM3 < 쏘울 < **코나 < 볼트** | — | — |

정밀검사율은 모형 손익배수와 **완전히** 같은 서열이다(타우 +1.000). 최적정책이
경제 서열을 그대로 따른다는 내부 정합성 확인이다.

실측 손익배수와는 6쌍 중 4쌍 일치·1쌍 역전·1쌍 동점(SM3·쏘울은 둘 다 0%),
켄달 타우 **+0.600** 이다. 역전은 오직 **볼트 대 코나** 한 쌍이다.

이 서열은 W=4~7 네 값 모두에서 같다 — 표본 하나의 우연이 아니다.

역전의 출처는 §1 에서 이미 나왔다. 모형은 볼트를 **+45.9%** 과대예측하는데
(넷 중 최대) 코나는 −2.8% 로 거의 정확하다. 그래서 모형 안에서는 볼트(3.17)가
코나(2.79)보다 위에 서고, 실측에서는 코나(2.89)가 볼트(1.99)보다 위에 선다.
§2 의 `p_rc` 차종 무관 문제도 같은 방향으로 작용한다.

> **논문 문장** — "가격 자료를 전혀 보지 않고 푼 최적정책은, 독립적으로 계산한
> 실거래 손익배수가 손익분기 아래로 놓은 두 차종(SM3·쏘울)에 정밀검사를 한 번도
> 배정하지 않고 위로 놓은 두 차종(볼트·코나)에만 배정한다 — 4/4 일치. 강도의
> 서열까지 보면 켄달 타우 +0.600 으로, 유일한 역전(볼트·코나)은 헤도닉이 고SOH
> 구간에서 볼트를 +45.9% 과대예측하는 데서 나온다."

## 무엇을 못 했나

TASK 값 인용이며, §2 의 기간별 분해는 거래일자 열이 없어 못 했다. §3 은 전부 했다.
